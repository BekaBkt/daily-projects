# daily-projects

A new small frontend project every day. React, TypeScript, UI experiments.

Each folder in [`projects/`](projects) is a self-contained project with its own README: what it is, what I practiced, and how to run it.

## Formats

| Format | What it is |
| --- | --- |
| 🧩 Component | One polished, reusable React + TS component |
| 📱 Mini-app | A small working app (timer, tracker, game, tool) |
| 📝 TIL | A short write-up with runnable examples about something I learned |
| 🧠 Algorithm | A problem solved in TypeScript, with tests and complexity notes |
